# Kinetix Nutrition · sitio web

Sitio de C-PRIX en un solo archivo (`index.html`): beneficios, cómo se usa, calculadora de plan de carrera y tienda con pedido por WhatsApp.

Se publica en Netlify sin paso de build: carpeta de publicación `/`, comando de build vacío.

Precios de HYD-PRIX y RAW provisionales: se editan en la constante `P` dentro de `index.html`.
